# 实时字幕 iOS MVP

这是一个面向家庭通话场景的 iOS 实时字幕工具原型。

## 当前能力

- 打开 App 后自动开始实时字幕。
- 支持 URL Scheme：`captionbridge://start`。
- 支持 Siri / 快捷指令入口：`开始实时字幕`。
- 使用麦克风采集外放声音。
- 使用 Apple Speech Framework 做普通话实时转写。
- 大字字幕显示，最新一句突出。
- 最近几句话回看。
- 主题：黑底白字、白底黑字、黄字黑底、跟随系统。
- 字号调节。
- 手动横屏家庭模式。
- 屏幕常亮。
- 音量过低、环境过吵提示。
- 默认不保存音频。
- 结束时可保存文字记录、不保存清空，或暂时保留在屏幕。

## 使用方式

1. 用 Xcode 打开 `CaptionBridge.xcodeproj`。
2. 设置自己的 Team 和 Bundle Identifier。
3. 真机运行。
4. 接起电话、微信语音或视频通话后，打开扬声器外放。
5. 通过 App、Siri、快捷指令或 URL Scheme 打开字幕工具。

## 重要限制

iOS 不允许第三方 App 无用户动作自动跳到前台，也不允许普通 App 直接读取电话或微信的通话音频。

这版采用的是可上架、风险较低的方式：让 App 通过麦克风听外放声音并生成字幕。若通话 App 和字幕 App 在同一台 iPhone 上同时使用，麦克风占用和音频路由需要真机验证；最稳定的家庭方案通常是“通话设备外放 + 另一台 iPhone/iPad 做字幕屏”。
